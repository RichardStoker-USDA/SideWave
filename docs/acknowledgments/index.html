Acknowledgments

SideWave is built on the work of many open-source projects and research models. The people and teams behind these deserve proper credit. The main dependencies and models are listed below; the repository ACKNOWLEDGMENTS file contains additional notices.

Speech Recognition Models

NVIDIA Parakeet TDT v3 (0.6B)

The core speech recognition model. A 600-million parameter Token-and-Duration Transducer model trained by NVIDIA Corporation for multilingual automatic speech recognition. This is the model that turns your voice into text.

  • Author: NVIDIA Corporation
  • License: Creative Commons Attribution 4.0 International (CC-BY-4.0)
  • Source: huggingface.co/nvidia/parakeet-tdt-0.6b-v3
  • Modifications: The model has been converted from its original format to CoreML by FluidInference for execution on Apple's Neural Engine. No retraining or architectural changes were made.

NVIDIA Parakeet Realtime EOU 120M

The streaming model behind the gray live draft and end-of-utterance detection. Converted to CoreML by FluidInference.

  • Author: NVIDIA Corporation
  • License: Licensed by NVIDIA Corporation under the NVIDIA Open Model License
  • Source: huggingface.co/nvidia/parakeet_realtime_eou_120m-v1

Parakeet Ultra

Optional multilingual recognition with post-training by Moondream, based on NVIDIA Parakeet. The CoreML conversion is maintained by FluidInference under CC-BY-4.0. See the model card and attribution.

Nemotron 3 Diarization

NVIDIA's speaker detection model, converted to CoreML by FluidInference. Licensed under OpenMDW-1.1; see the model card and license.

Parakeet CTC 110M

A CTC-based encoder model used as a secondary rescoring pass for Vocabulary boosting. When you add terms to SideWave's Vocabulary, this model helps the speech recognizer lock onto them during segment finalization.

  • Author: NVIDIA Corporation
  • License: Apache License 2.0
  • Source: huggingface.co/nvidia/parakeet-ctc-0.11b

Silero VAD (v6)

The voice activity detector that identifies natural speech boundaries in real time. It supports silence filtering and configurable segment boundaries.

  • Author: Silero Team
  • License: MIT License
  • Source: github.com/snakers4/silero-vad

Frameworks and SDKs

FluidAudio

The Swift SDK that makes all of this possible on Apple Silicon. FluidAudio supplies model loading, CoreML inference, voice activity detection, and diarization. SideWave owns microphone routing, capture, and its vocabulary-boosting integration. It's the backbone of SideWave's entire speech recognition pipeline. FluidInference also maintains the CoreML conversions of the Parakeet and Silero models used by this app.

  • Author: FluidInference
  • License: Apache License 2.0
  • Source: github.com/FluidInference/FluidAudio
  • CoreML conversions: huggingface.co/FluidInference

Sparkle

The auto-update framework that checks for new versions of SideWave and handles the update flow. Used by a huge number of independent macOS apps.

  • Authors: The Sparkle Project contributors
  • License: MIT License
  • Source: github.com/sparkle-project/Sparkle

NeMo Text Processing

Inverse text normalization library that converts spoken-form text into written form (e.g., "twenty three" to "23", "december fifth" to "December 5"). Included through FluidAudio.

  • Author: NVIDIA Corporation
  • License: Apache License 2.0
  • Source: github.com/NVIDIA/NeMo-text-processing

MLX Swift LM

Apple's MLX inference runtime with language-model bindings for Swift. SideWave uses MLX Swift LM to run the Gemma 4 local models for Refine and meeting-transcript formatting on the Mac's GPU.

  • Authors: Apple Machine Learning Research and contributors
  • License: MIT License
  • Source: github.com/ml-explore/mlx-swift-lm

Swift Markdown

Apple and Swift contributors maintain the Markdown parser used for document and meeting output. It uses Apache 2.0 with the Swift Runtime Library Exception; its cmark dependency retains its BSD notices. Full notices are bundled with the app. See Swift Markdown.

Language Models

Gemma 4 (E2B, E4B, and 12B)

Local language models by Google DeepMind. E2B, E4B, and 12B are available for refinement, document editing, vocabulary assistance, and meeting notes through MLX. Weights download on demand from Hugging Face; processing runs on the Mac.

  • Authors: Google DeepMind
  • License: Apache License 2.0
  • Model weights: huggingface.co/mlx-community (4-bit MLX conversions)

Apple Foundation Models (Apple Intelligence)

On macOS 26 Tahoe and later, SideWave can optionally use Apple's built-in language model for Refine and for short meeting transcripts. Model assets are managed by macOS and must be enabled and ready. SideWave has no separate model download for this backend. The model runs on-device through the FoundationModels framework. Apple manages the model runtime; SideWave passes prompts to the framework the same way any other app does.

  • Author: Apple Inc.
  • Distribution: Ships with macOS 26 Tahoe and later, on Apple Intelligence-eligible Macs
  • Documentation: developer.apple.com/documentation/foundationmodels

Apple Platform

SideWave is a native macOS application built with Swift and SwiftUI, targeting Apple Silicon Macs running macOS 26 or later. It uses Apple's CoreML framework for on-device model inference on the Neural Engine, AVFoundation for audio capture, and AppKit where native APIs are needed (global hotkey capture, overlay panels, accessibility, text injection). None of these require attribution, but they deserve acknowledgment as the foundation the app runs on.

Thank You

The open-source projects, research papers, and model releases that SideWave builds on represent thousands of hours of work by many people. Speech recognition that runs entirely on-device with this level of accuracy was science fiction not long ago, and it only works now because researchers published their models and engineers built the tooling to run them on consumer hardware. If you find SideWave useful, consider giving the upstream projects a star, a donation, or a contribution.
